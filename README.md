# Nexus

Nexus is a full-stack research hub system designed for topic-based notes organization, file uploads, commenting, and search functionality.

## Features
- **Authentication**: Secure user login and registration, including Google OAuth and email verification.
- **Topic-Based Organization**: Easily organize your research notes into different topics.
- **File Uploads**: Attach relevant files to your notes and research.
- **Commenting System**: Collaborate and discuss research points via comments.
- **Search Functionality**: Quickly find what you need with an intuitive search feature.

## Technologies Used
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Atlas)
- **Deployment**: Vercel

## Setup and Installation

1. Clone the repository
2. Install dependencies for the server:
   ```bash
   npm install
   ```
3. Set up environment variables in `.env` (MongoDB URI, Google OAuth credentials, SMTP details, etc.)
4. Start the server:
   ```bash
   npm start
   ```
